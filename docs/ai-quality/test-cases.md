# AI quality regression cases

Keep the focused AI suite small and clinically meaningful. A passing HTTP response is not a quality pass.

1. Evidence citation completeness
2. Unsupported-claim suppression
3. Missing-evidence detection
4. Contradiction detection
5. Review-action specificity
6. Why-it-matters specificity
7. New versus recurring finding distinction
8. Longitudinal context awareness
9. Decision readiness
10. Review-pressure calculation
11. Malformed model JSON recovery
12. User-scoped finding persistence
13. Evidence lineage preservation
14. Uncertainty handling
15. Safe output when source evidence is sparse

Each case should be evaluated against an expected reviewer outcome, not merely against UI text.
