# TrialIQ Demo Source Records

These synthetic source records are the canonical, human-readable content used to design and validate TrialIQ demo documents. They intentionally include realistic operational context, explicit missing information, protocol guardrails, source evidence, and review states so the AI is tested on evidence quality rather than toy one-line inputs.

## Quality principles
- No real patient data.
- Missing information is intentional and should remain missing in AI output.
- Protocol thresholds are only authoritative where explicitly documented.
- Observations must not be upgraded into diagnoses, confirmed safety signals, causality or regulatory conclusions.
- Medical coding suggestions always require qualified human review.
