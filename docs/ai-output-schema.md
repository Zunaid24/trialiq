# TrialIQ AI output contract

A useful TrialIQ clinical result should preserve this chain:

**Observed evidence → Clinical interpretation → Why it matters → Priority → Evidence gaps → Review action → Decision readiness**

- **Observed evidence:** directly supported facts from source records.
- **Clinical interpretation:** cautious interpretation tied to those facts.
- **Why it matters:** clinical or operational significance.
- **Priority:** relative review urgency, not an unsupported diagnosis.
- **Evidence gaps:** information that could change the assessment.
- **Review action:** a concrete next verification step.
- **Decision readiness:** whether the available evidence supports closing the review.

The model must not invent citations, patient facts, measurements, protocol requirements, or definitive conclusions when evidence is incomplete.
