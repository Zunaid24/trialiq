# TrialIQ Professional Synthetic Demo Records

These files are synthetic demonstration source records for TrialIQ's clinical AI modules.

## Files

- `protocol-demo.pdf` — protocol screening criteria and evidence rules
- `participant-demo.pdf` — participant screening summary
- `lab-demo.pdf` — screening hematology and chemistry
- `medication-demo.pdf` — current and recent medication reconciliation
- `adverse-event-demo.pdf` — initial adverse-event report
- `deviation-demo.pdf` — confirmed protocol deviations
- `safety-demo.pdf` — participant-level safety signal review

## Design principles

The records deliberately include:
- explicit source evidence
- missing-information states
- protocol boundaries
- review requirements
- distinction between documented facts and unresolved questions
- realistic cross-document relationships

All records are synthetic and contain no real patient information. They are not for clinical decision-making.
